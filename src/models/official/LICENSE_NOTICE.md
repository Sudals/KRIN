# Third-party code

The files in this directory are model definitions taken from the released
repositories of the five published methods the paper compares against. They are
included unmodified so the released-implementation arm runs the authors' own
code; only the adapters in `../official_wrap.py`, which map this paper's task
onto those definitions, are ours.

Each file keeps the licence of the repository it came from. Refer to those
repositories for the authoritative terms, and remove this directory if the
release cannot redistribute them.
